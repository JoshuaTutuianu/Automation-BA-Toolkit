Business Analysis Toolsuite

Automation BA Toolkit

Complete Business Analysis workflow — from process mining to business case

A suite of five linked browser-based tools that replicate the complete BA workflow for both classic RPA and probabilistic AI agents. Built as a portfolio piece demonstrating practical Business Analysis methodology — no installation, no accounts, entirely in the browser.

The Workflow

Tools pass data via URL parameters — stateless, shareable, and independently usable at any point in the workflow.

The Tools
Tool 0 · Entry Point
Process Mining Visualizer
Upload a CSV event log to map process flows, surface bottlenecks, detect outliers, and assess automation potential with hard data before any scoping begins. Powered by D3.js flow graphs.
Open Tool →
Tool 1 · Assessment
Process Assessment Tool
Based on UiPath's automation suitability scoring model. Eliminatory gates, postponement flags, and weighted scoring across ease of implementation and benefit — determines if a process is worth automating.
Open Tool →
Tool 2 · Classic RPA
Classic RPA PDD Planner
Structures the Process Design Document for deterministic, hard-coded robots. Maps the exact “happy path” with strict exception handling across 7 phases. Generates Mermaid.js flowcharts.
Open Tool →
Tool 3 · AI Agents
Agentic Automation Planner
Structures design documents for probabilistic AI agents. Maps objectives, tool boundaries, guardrails, and blast-radius containment instead of step-by-step instructions. Includes capability map generation.
Open Tool →
Tool 4 · Financial
Business Case Builder
Structures financial justification and executive sign-off. Live ROI dashboard, Chart.js cumulative cash flow graph, and a multi-turn conversational AI CFO that challenges costs and savings assumptions.
Open Tool →
